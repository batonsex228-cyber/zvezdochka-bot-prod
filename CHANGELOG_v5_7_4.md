# v5.7.4 — Greeting / first-contact UX hotfix

Дата: 2026-09-09

## Что исправлено

- Простые приветствия (`Здравствуйте`, `Привет`, `Добрый день`, `Добрый вечер`, `Доброе утро`) больше не уходят в fallback и не создают заявку специалисту.
- На приветствие бот отвечает приветствием, коротко представляется как помощник службы поддержки ДЗЛ «Звёздочка» и предлагает задать вопрос.
- Сообщение вида `Добрый вечер, подскажите время заезда` обрабатывается как обычный вопрос, но ответ начинается с `Добрый вечер`.
- Sticker-only сообщение во VK больше не получает сухой ответ `Напишите вопрос текстом`. Бот отвечает дружелюбным приветствием и показывает основное меню.
- Для других вложений без текста добавлен человеческий нейтральный ответ вместо ошибки обработки.
- Убрано повторяющееся `Конечно!` из основных карточек/кнопочных ответов. Ответы теперь начинаются сразу по сути и отличаются по формулировке в зависимости от раздела.
- Кнопка `Задать свой вопрос` теперь отвечает `Задавайте 😊` вместо очередного `Конечно`.

## Безопасность

- Логика достоверности, dynamic availability и передача специалисту не ослаблялись.
- Приветствия обрабатываются до слоя поиска знаний, поэтому одно слово `Здравствуйте` не может случайно создать обращение оператору.
