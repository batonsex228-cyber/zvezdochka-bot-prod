# v6.0.2 — UX POLISH: SMALL TALK + TYPING + BOOKING COPY

## Что исправлено

### 1. Этикет и короткие сообщения больше не создают тикет менеджеру
Бот отдельно обрабатывает сообщения, которые сами по себе не являются вопросом: благодарность, прощание, нейтральное подтверждение, короткий ping и emoji-реакции.

Примеры:
- `Спасибо` → `Всегда пожалуйста 💛 ...`
- `До свидания` / `Всего доброго` → дружелюбное прощание без handoff.
- `Понятно`, `Окей`, `Супер` → короткий нейтральный ответ.
- `Ау`, `Вы тут?`, `???` → бот сообщает, что он на связи.
- `👍`, `💛`, `🙏` → реакция без тикета менеджеру.

Классификатор работает по целому сообщению, а не по подстроке: `Спасибо, а какие документы нужны?` остаётся обычным вопросом и идёт в основной FAQ/router.

### 2. Индикатор «печатает…» работает на всех входящих сообщениях и callback-кнопках
Для каждого `message_new` и `message_event` запускается best-effort typing keepalive. Он отправляет `messages.setActivity(type=typing)` сразу и обновляет его каждые 4 секунды, пока обработчик не завершится. Это особенно заметно на Google Booking, где запрос может занимать несколько секунд.

Ошибки `setActivity` не блокируют и не задерживают основной ответ.

### 3. Бронирование стало дружелюбнее и понятнее
Сбор данных оформлен как три понятных этапа:
- `шаг 1 из 3 · Дата и время`
- `шаг 2 из 3 · Гости`
- `шаг 3 из 3 · Контакты`

Тексты стали мягче, но остались короткими. Для беседки бот подсказывает минимальную длительность из текущих правил услуги и максимальное число гостей из Google Sheet.

Финальное подтверждение и менеджерское подтверждение не менялись.

- Структура Google Sheet не менялась.
