# ДЗЛ «Звёздочка» — v6.0.4 / SHIFT APPLICATIONS

**База:** полная, повторно проверенная сборка v6.0.3 FINAL REAUDITED. **Канал клиента:** сообщения VK; **оператор:** менеджер в VK; **хранилище:** SQLite + опциональный Google Apps Script.

## Новый функционал

- Понимание запросов родителей «Хочу купить путёвку на первую смену», «Хочу записать ребёнка на смену» и аналогичных.
- Выбор смены: настраиваемые номера 1–5, по умолчанию 1–3. Четвёртая отмечена как занятая по опубликованной информации, пятая резервная без выдуманных дат.
- Проверка отдельного явного согласия и ссылки на действующую HTTPS-политику обработки ПД *до* ввода данных ребёнка.
- Пошаговая анкета: ФИО ребёнка, дата рождения, ФИО родителя, телефон, проверка и повторное заполнение.
- Одна заявка с уникальным номером `ZV-XXXXXXXXXXXX` после подтверждения анкеты. Ответ содержит ссылку на документы.
- SQLite транзакционно фиксирует заявки, включая обращения при недоступности Google API. Повторная отправка Google выполняется без дублирования строк.
- Менеджеру VK приходит карточка с кнопками «Подтвердить» / «Отменить»; ответ идёт родителю; команда `#смены` выводит открытые заявки.
- Apps Script создаёт вкладки «Смена 1»…«Смена 5», заголовки на русском и фильтры; Google-интеграция обновляет статусы заявок по идентификатору.
- Отдельный юридический переключатель `SHIFT_EXPORT_PII_TO_GOOGLE` и проверка `SHIFT_PII_EXPORT_ALLOWED` в GAS: **по умолчанию ПД детей не передаются в Google**.
- Отсутствует автоматическое резервирование места или покупка путёвки — подтверждение осуществляет менеджер.

## Безопасность совместимости

- Существующий модуль аренды, цена/даты беседок, Smart Handoff, FAQ, база знаний, менеджерские тикеты и Docker не заменяются.
- Новый сценарий включается только после настройки `SHIFT_BOOKINGS_ENABLED=true` и обязательных параметров.
- Патч накладывается **строго поверх v6.0.3 FINAL REAUDITED**, без замены рабочего `.env` или `runtime/bot.sqlite3`.
- Временные данные анкеты автоматически устаревают через 24 часа.

## Проверки

Выполнить из корня проекта:

```bash
python scripts/self_test.py
python -m unittest -v tests.test_v604
node google_apps_script/self_test.js
python scripts/preflight.py
```

Важное ограничение: эти тесты не подтверждают прохождение живых заявок через VK и реальный Apps Script. Для этого используйте чек-лист из `google_apps_script/SHIFT_APPLICATIONS_SETUP_RU.md` после развертывания.
