# Zvezdochka Support Bot v5.7.1 — Booking handoff patch

Эта версия основана на v5.7 LIVE LANGUAGE и усиливает обработку вопросов о текущей доступности.

## Что изменено

- «Свободна ли беседка на 13 сентября?» -> только специалист.
- «Есть ли свободная беседка на 13 сентября?» -> только специалист.
- «Хочу арендовать беседку» -> затем «А на 13 сентября?» -> только специалист.
- Текущее наличие путёвок/мест -> только специалист.
- Бот не имитирует календарь занятости и не угадывает свободные даты.
- Родитель получает отдельный естественный текст про отправленный запрос.
- В тикете менеджеру есть пометка о необходимости проверить актуальную доступность / бронирование.
- Текущее наличие по-прежнему нельзя сохранить в базу знаний даже как временный факт.

## Обновление существующего v5.7

Из корня проекта:

```bash
unzip -o zvezdochka_support_bot_v5_7_1_BOOKING_HANDOFF_PATCH.zip -d .
chmod +x APPLY_V571.sh
./APPLY_V571.sh
```

После этого проверить версию:

```bash
python -c "from app.version import VERSION; print(VERSION)"
```

Ожидается:

```text
5.7.1
```

И затем живое подключение VK в Codespace:

```bash
python scripts/test_vk_connection.py
```

## Чистая установка

Можно вместо патча распаковать `zvezdochka_support_bot_v5_7_1_BOOKING_HANDOFF_FULL_CLEAN.zip` в пустую папку репозитория, затем добавить свои Secrets/.env и запустить обычный сценарий Codespaces.
