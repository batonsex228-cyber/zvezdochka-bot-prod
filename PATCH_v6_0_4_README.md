# PATCH v6.0.4 — заявки на лагерные смены

**Применять только поверх v6.0.3 FINAL REAUDITED**, загружая файлы в корень GitHub-репозитория с заменой одноимённых.

1. Создать резервную копию `.env` и SQLite базы Docker-volume (не включать их в GitHub).
2. Распаковать patch ZIP в корень проекта, подтвердив замену существующих файлов.
3. Запустить `bash APPLY_V604.sh` — он проверяет офлайн-тесты.
4. Прочитать `google_apps_script/SHIFT_APPLICATIONS_SETUP_RU.md` и обновить Google Apps Script в **существующем** Web App, вызвав `setupSpreadsheet()`.
5. Только после настройки HTTPS-страницы обработки ПД, `VK_MANAGER_USER_ID` и действующего Google API установить `SHIFT_BOOKINGS_ENABLED=true`.
6. Опубликовать новую версию Docker-образа через GitHub Actions; проверить по тестовой заявке и Google Sheets.

По умолчанию новая функция выключена, персональные данные детей в Google не выгружаются. Для включения **полного** экспорта нужны отдельные правовые основания и двойное разрешение. Это не онлайн-продажа путёвок и не подтверждение наличия мест.
