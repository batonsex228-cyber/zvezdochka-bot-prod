# ДЗЛ «Звёздочка» — Support Bot v5.7 LIVE LANGUAGE · VK-FIRST

Предрелизная VK-first версия первой линии поддержки лагеря. Пользователь пишет в обычные **сообщения сообщества VK**; бот отвечает из проверенной базы, уточняет неоднозначные вопросы и передаёт всё, в чём не уверен, специалисту.

## Что нового в v5.7

- Бот понимает больше реальных формулировок родителей из живых диалогов: заезд, договор, телефоны, НДФЛ, аренда/ночёвка, офис и посещения.
- В `#меню` появилась `📚 База знаний`: менеджер сам добавляет постоянные и временные знания без правки Python-кода.
- Временное знание можно ограничить 1/7/30/90 днями; после срока оно автоматически перестаёт участвовать в ответах.
- Наличие путёвок/мест и свободные даты беседок/корпусов принципиально не кэшируются и всегда идут специалисту.
- Реальные чаты используются как язык и как источник только для явно утверждённых фактов; старые цены/даты не переносятся вслепую.

Подробно: `CHANGELOG_v5_7.md` и `KNOWLEDGE_BASE_GUIDE.md`.

## Основа v5.6, сохранённая в v5.7

- Telegram полностью исключён из production runtime и зависимостей.
- VK Bots Long Poll — основной транспорт. Для теста в Codespaces не нужен webhook.
- Стабильный intent-router понимает разговорные формулировки вроде `скок 2-я стоит?`, `а 2-я когда?`, `справка 079 нужна?`.
- Контекст диалога хранится 15 минут: `Когда вторая смена?` → `А сколько стоит?`.
- Неоднозначные запросы уточняются кнопками, а не угадываются.
- `📅 Смены и цены` закреплена отдельным проверенным ответом и не зависит от crawler/runtime snapshot.
- Для смен используется VK-карусель с безопасным текстовым fallback.
- Перед обработкой сложного вопроса отправляется `typing` activity.
- Неизвестный/чувствительный/динамический вопрос создаёт тикет, отмечает диалог как важный и неотвеченный и отправляет карточку менеджеру.
- Менеджер отвечает кнопкой `✍ Ответить` или командой `#номер текст`.
- Админ-панель внутри VK: `#меню`, `#stats`, `#open`, `#рассылка`.
- Добровольная подписка на важные уведомления и рассылки только подписавшимся пользователям.
- Аналитика: пользователи, сообщения, кнопки, автоответы, эскалации, 👍/👎, containment rate, подписчики и проблемные FAQ.
- Официальный профиль `zvezdochkaooorazvitie` используется как вторичный источник.
- `VK_CONTENT_TOKEN` необязателен. Без него бот работает полностью; импорт последних постов просто выключен.
- В источниках действует приоритет: утверждённый FAQ → сайт → профиль VK → свежие посты VK.

## Обязательные секреты

```text
VK_GROUP_TOKEN
VK_GROUP_ID
```

Для рабочего handoff/admin режима рекомендуется:

```text
VK_MANAGER_USER_ID
```

Опционально позже:

```text
VK_CONTENT_TOKEN
OPENAI_API_KEY
```

Не храните реальные токены в репозитории или `.env.example`.

## Быстрый запуск в GitHub Codespaces

```bash
python scripts/self_test.py
python scripts/test_vk_connection.py
bash START_CODESPACE.sh
```

`test_vk_connection.py` проверяет `message_new` и `message_event`. В v5.7 оба события обязательны: без `message_event` не работают feedback/admin callback-кнопки.

## Менеджерский режим

Пользователь с ID из `VK_MANAGER_USER_ID` пишет в обычный диалог с тем же сообществом:

```text
#меню
#stats
#open
#рассылка
#знания
```

При неизвестном вопросе менеджеру приходит тикет. Ответить можно кнопкой `✍ Ответить` или:

```text
#17 Текст ответа родителю
```

Ответ автоматически возвращается пользователю в VK.

## Рассылки

Пользователь сначала добровольно включает `🔔 Важные уведомления`. Администратор запускает `#рассылка`, отправляет текст, видит предпросмотр и число получателей и подтверждает отправку. Получатели отправляются пакетами не более 100 peer IDs. Если VK отклоняет newsletter intent, пакет не маскируется под обычное сообщение: ошибка попадает в отчёт администратору.

## База знаний менеджера

`#меню` → `📚 База знаний` позволяет добавить утверждённый вопрос/ответ и синонимы. Постоянные знания предназначены для устойчивых правил; цены, даты, графики и сезонные факты добавляются как временные. Изменения доступны сразу и хранятся в `runtime/bot.sqlite3`.

Подробная инструкция: `KNOWLEDGE_BASE_GUIDE.md`.

## Безопасность

Бот не должен угадывать:

- наличие путёвок/мест прямо сейчас;
- индивидуальные медицинские ситуации;
- персональные данные;
- непроверенные правила возврата/оплаты;
- точный адрес лагеря, если опубликован только адрес офиса.

Такие вопросы передаются специалисту.

Основной FAQ и зафиксированные UI-ответы имеют больший приоритет, чем вторичные данные VK. Профиль/посты VK не делают старый снимок сайта «свежим» и не подтверждают автоматически постоянные FAQ.

## Проверка

```bash
python scripts/self_test.py
```

Релизная сборка должна завершаться строкой:

```text
ALL OFFLINE TESTS PASSED — 184 TESTS
```

Это офлайн/интеграционная проверка кода. Реальные права токена и Long Poll отдельно проверяются `python scripts/test_vk_connection.py` уже в Вашем Codespace.

## Сервер

Для production можно использовать Docker Compose или systemd. Смотрите `SERVER_DEPLOY.md`. Runtime-база `runtime/bot.sqlite3` содержит тикеты, оценки, подписки и аналитику — её нужно хранить на постоянном диске и резервировать.

## GitHub Actions / Docker production deployment

Для сборки Docker-образа без Docker Desktop используйте `.github/workflows/docker-publish.yml`.
Полная инструкция: `GITHUB_ACTIONS_DEPLOY.md`. Production compose: `docker-compose.prod.yml`.
