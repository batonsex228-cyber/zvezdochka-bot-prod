# VK test setup — v5.7

## Сообщество
- Сообщения сообщества: включены.
- Возможности ботов: включены.
- Long Poll API: включён.
- События: `message_new` + `message_event`.
- Community token: права на сообщения и управление сообществом.

## Codespaces secrets

```text
VK_GROUP_TOKEN=<секретный community token>
VK_GROUP_ID=<числовой ID без минуса>
VK_MANAGER_USER_ID=<личный числовой ID менеджера>
```

Опционально позже:

```text
VK_CONTENT_TOKEN=<service/user token для чтения последних wall posts>
```

## Live check

```bash
python scripts/test_vk_connection.py
```

Проверяются Long Poll, оба message events, официальный source-profile и доступность manager inbox.

## Живой тест
1. Нажать `📅 Смены и цены` — должен прийти ответ + карусель либо текстовый fallback.
2. Нажать 👍 — feedback записывается.
3. Нажать 👎 — вопрос передаётся специалисту.
4. С другого аккаунта задать неизвестный вопрос — менеджеру приходит тикет.
5. Менеджер нажимает `✍ Ответить` и пишет ответ — он возвращается исходному пользователю.
6. Менеджер пишет `#меню` → проверяет статистику/открытые вопросы/рассылку.
7. Пользователь включает `🔔 Важные уведомления`, после чего попадает в добровольную рассылку.
